# ROBAN语义重建与主动场景核查任务设计

更新日期：2026-11-12  
状态：已确定的功能与下游任务方案，功能尚未全部实现。  
本轮范围：任务定义、用户交互、输出结果与验收标准。

项目目标是让 ROBAN 建立可复用、可定位、可查询的三维场景地图，并利用空间记忆与主动观察完成实验工位物品核查。综合应用为“具有空间记忆的实验室物品核查助手”；抓取、整理与大范围自主巡检列为后续扩展。

**1. 基于ROBAN的场景三维重建**

用户任务：让机器人观察指定区域，建立场景三维表示，并保存供后续重新使用。

主要功能：

- 将不同观测融合为彩色点云；条件允许时提供网格。
- 显示已观测表面、缺失区域和重建范围。
- 保存地图，支持下次加载和继续观察。
- 在地图中标记实验台、托盘、收纳区等用户指定区域。

任务输出：场景点云或网格、地图文件、区域标记、观测覆盖情况。

验收方式：检查地图能否保存和重新加载；用已知尺寸物体或参考扫描评价几何误差和可观测表面覆盖率。没有观察到的背面不视为已恢复表面。

**2. 地图复用定位与重定位**

用户任务：重新打开已有地图后，确定当前观测位置和朝向；跟踪短暂丢失时尝试重新定位。

主要功能：

- 显示地图中的当前相机位置、朝向和轨迹。
- 明确显示定位正常、跟踪丢失、重定位中等状态。
- 重新启动后，判断是否处于已建图场景并尝试恢复定位。
- 如允许地图继续更新，在已有地图基础上新增观测。

任务输出：地图中的相机位姿、轨迹、定位状态和置信信息。

概念约定：建图阶段的 SLAM 同时估计位姿并维护地图；地图建立后的主要任务是定位与重定位。第一版先输出相机位姿，补齐相机到机器人本体的外参后，再输出机器人底座位姿。

验收方式：评价相对位姿误差、静止漂移、跟踪失败次数、重定位成功率与耗时。没有参考轨迹时，不能仅凭算法返回成功就声称定位准确。

**3. 语义分割与三维地图查询**

用户任务：理解地图中物体的类别、位置、数量和空间关系，并通过简明指令检索。

查询示例：

| 查询类型 | 示例 | 预期输出 |
|---|---|---|
| 类别查询 | 地图里有哪些瓶子 | 高亮匹配的物体 |
| 位置查询 | 纸盒在哪里 | 地图位置与对应观测 |
| 数量查询 | 托盘上有几个瓶子 | 指定区域内的实例数量 |
| 空间关系 | 工具盒旁边有什么 | 邻近物体及其关系 |
| 观测完整性 | 哪些地方没有看清 | 未观测或遮挡区域 |
| 历史查询 | 工具盒上次在哪里 | 最近确认的位置与时间 |

任务输出：带语义标签的三维地图、物体实例标记、检索结果与证据画面。

范围约定：先支持少量预定义物体类别和有限查询句式。语义分割提供类别，数量与历史跟踪还需要区分物体实例；同一物体的多次观测不能重复计数。外观无法区分的同类物体应保留身份不确定状态。

验收方式：评价类别分割质量、实例计数误差、目标检索准确率、空间关系判断准确率与查询耗时。

**4. 主动补扫与地图更新**

用户任务：让机器人优先补充有用观测，更新未看清或发生变化的区域。

主要功能：

- 标记遮挡、深度缺失、语义不确定或观测过期的区域。
- 在有限可达候选视角中，选择对当前任务最有帮助的下一方向。
- 获得新增证据后更新地图，避免重复扫描已经充分确认的区域。
- 达到任务要求、观测次数上限或没有有效候选视角时停止。

任务输出：推荐观察方向、选择原因、补扫结果及仍无法确认的区域。

四视角约定：四个方向是有限候选观测，不是默认绕物体一周。转头主要改变观看方向，并不保证产生足够平移以看到物体背面。若可达视角均无法消除遮挡，结果保持“待确认”。

验收方式：比较单次观察、固定四视角与主动选择视角，在相同场景和观测预算下评价任务完成率、覆盖改善、观察次数与总耗时。

**5. 综合应用：具有空间记忆的实验室物品核查助手**

应用目标：帮助实验室或工具间核查指定物品是否齐备、是否位于指定区域，以及相对参考状态发生了什么变化。

典型指令：

> 帮我检查实验工位，确认物品是否齐全、是否放回指定区域；有疑问的地方再看一下。

这里的“准备齐全”只指指定物品及摆放要求；不据此判断仪器电气状态、功能是否正常或实验操作是否安全。

任务流程：

1. 建立参考状态：记录目标物品、三维位置、所属区域和最后确认时间。
2. 重新定位：将当前观测与历史地图对齐。
3. 初步核查：识别新增物体、位置变化和未再次观察到的预期物体。
4. 主动复核：针对遮挡或证据不足的目标补充观察。
5. 更新记录：保存当前确认的位置、变化状态与观测时间。
6. 输出报告：在地图中高亮异常，附上画面、时间和结论依据。

结果类别：

| 状态 | 含义 | 示例 |
|---|---|---|
| 已确认在位 | 当前证据支持目标位于指定区域 | 工具盒位于左侧收纳区 |
| 已确认移位 | 目标实例在其他位置被重新找到 | 工具盒从收纳区移到桌面中央 |
| 新增物体 | 当前出现参考状态中没有记录的物体 | 托盘新增一个纸盒 |
| 区域内未发现 | 对预期区域取得足够观测后仍未检出目标 | 右侧托盘已检查，未发现原来的瓶子 |
| 待确认 | 遮挡、深度缺失或实例匹配不确定 | 设备盒所在区域被挡住 |

“区域内未发现”只针对已检查范围，不等于证明物体在整个环境中不存在。历史位置和历史画面也不能代替当前确认。

本应用的项目特色：

- 空间与时间记忆：支持过去和当前状态比较。
- 不确定性表达：区分未看到、身份不确定与区域内未发现。
- 任务驱动主动观察：把有限观测用于当前核查目标。
- 证据关联：每条核查结论关联三维位置、观测时间和画面。

**6. 综合演示设计**

场景采用一个固定工位，放置3至5个易区分、尺寸适中的物体，例如工具盒、纸盒和不透明瓶子，划分收纳区、托盘区和工作区。第一版在可达头部视野内演示，不依赖自主行走。

演示顺序：

1. 建立并保存工位地图，登记参考摆放状态。
2. 重新加载地图并完成定位。
3. 查询指定物品，显示三维位置和最近观测。
4. 人为移走一个物体、挪动一个物体，并遮挡另一个物体。
5. 发出工位核查指令。
6. 系统指出变化和疑点，主动选择观测方向复核。
7. 输出核查结果，明确区分已确认和待确认项。

如果遮挡在全部可达视角中都无法解除，演示结果应是待确认，而不是强行宣布物品丢失。

**7. 对照实验与验收**

| 对照方案 | 目的 |
|---|---|
| 单次当前观察 | 评价单视角核查能力及遮挡误报 |
| 历史地图加固定四视角 | 评价地图记忆与固定补扫的效果 |
| 历史地图加主动选择视角 | 评价任务驱动复核是否提高效率 |

三种方案使用相同物体、参考地图、变化事件、可达视角和查询要求，并重复不同摆放顺序。

主要指标：

- 物体状态分类准确率及各类精确率、召回率。
- 将遮挡或未充分观察误判为缺失的比例。
- 移位目标重新找到的成功率。
- 核查覆盖率与最终待确认项比例。
- 每个正确结论的观察次数、总耗时和数据传输量。
- 错误结论被标为高置信度的比例。
- 地图定位和重定位质量，避免把定位偏差误判为物体移动。

报告需联合展示准确性、耗时与待确认比例：不能通过把所有目标都标为待确认来获得低误报。

**8. 必做功能与扩展范围**

必做：场景重建和地图保存加载、相机在地图中的定位、有限类别语义查询、工位参考状态与当前状态核查。

主要加分项：有限视角下的任务驱动主动复核，以及带空间位置、时间和画面的核查证据。

后续扩展：更丰富的指令与物体类别、大范围自主巡检、物品取放和整理。真实抓取成功率只在完成真实执行实验后统计。

三维语义地图和语言检索已有代表工作[ConceptGraphs](https://concept-graphs.github.io/)。本课程项目的特色定位为有限观测预算下的空间记忆与主动异常复核，具体收益通过上述对照实验验证。

本方案沿用“场景重建—地图定位—语义查询—主动补扫”的主线，新增综合应用任务；不在本轮确定模型、通信协议、控制实现或部署架构。
