# 2026年11月15日一米有线范围建图安排

更新日期：2026-11-14。根据最新现场条件：暂时没有电池，一根线需连接电脑主机，活动范围约一米，先做小规模测试。线缆具体承担供电、网络、USB或其他功能尚未核实。

**当天验收目标**

完成一个固定工位附近的局部彩色三维地图：通过人工单步在松弛线缆允许的范围内获取小幅平移和转向观测，在电脑融合，并保存、重新加载。记录真实动作量、原始RGB-D、相机参数和轨迹。

完整实验室地图保留为后续目标。当前不能把局部图当作全室图，也不能假定仅转头即可覆盖遮挡背面。

**先确认有线条件**

到场前20分钟由现场核对：

- 这根线连接哪两个接口，承担什么功能；不要仅凭“连主机”认定为供电线。
- 机器人实际如何供电，是否为支持该型号和动作负载的原装方案；能开机不代表已验证行走负载。
- 哪个设备固定、哪个可移动，线是否穿过脚边，起点有多少松弛余量。
- 在地面标记可用工作区域，不把约一米活动范围全部用满。先确定一段很短的试走路径，线有拉力或靠近脚部时不继续。
- 查清断开该线的后果；实验中不通过拔线或拔电源试探停机。
- 若供电或步态能力无法确认，改做静止图像、尺度、点云保存和资料核对，不开展行走。

这些检查是明天的条件确认，不是本轮已经验证通过。

**约4小时核心安排**

| 到场后时间 | 内容 | 必须保存 |
|---|---|---|
| 0—20分钟 | 核对线缆、供电、网络、控制源、相机视野 | 接口/走线照片、设备快照 |
| 20—65分钟 | 单步模式、控制接管和停止检查 | 按键/命令/反馈日志、实际落脚与位移视频 |
| 65—90分钟 | 60秒数据质量和两段30秒静止基线 | RGB-D、内参、尺寸参考 |
| 90—150分钟 | 同一工位的微小平移与小角度转向 | 逐步采集数据与停稳阶段标记 |
| 150—210分钟 | 电脑重建，检查尺寸、重影与保存读回，补采关键缺口 | 地图、轨迹、参数、误差记录 |
| 210—240分钟 | 重复最重要的一条路线、备份和收尾 | 重复数据、最终状态与待办 |
| 额外时间 | 分析失败原因、核对整机外参和后续全室方案 | URDF/接口说明/工位布局草图 |

每次运动必须先通过单步验收。到约80—90分钟仍无法安全接管，则把剩余时间投入静止质量、设备资料和电脑端重建，运动验证标为未完成。

**单步模式的必测项**

本轮计划没有修改遥控程序，单步版本仍是出发前待完成项。

- 待命不动；一次按下只发一次非零步态命令。
- 长按5秒不连续行走；松开后再次按下才生成新事件。
- 当前动作未完成时不排队，完成后不能补走旧事件。
- 用本体反馈确认完成；没有完成反馈不能自动重试。
- 记录实际落脚次数，确认厂商一个步态命令对应的最小可停稳动作单元。
- 先在静止状态验证停止、失焦和通信中断，再由现场判断能否测试最小动作中的异常。
- 线缆限制必须由现场观察和工作区标记控制，当前软件不能感知线缆拉力。

**小范围采集路线**

固定选择有桌椅边缘、纸盒、墙角或其他纹理的目标区，并放入一个已知尺寸物体。把起点记为A，各条路线分别从A开始，先后各静止5秒。

| 编号 | 动作安排 | 初始建议 | 重复 |
|---|---|---|---|
| L0 | 保持静止 | 两段各30秒 | 2段 |
| L1 | 小幅改变朝向，再回起始朝向 | 以验收允许的少量角度、逐次动作完成 | 3次 |
| L2 | 小幅平移后停稳 | 先以实测累计约5—10厘米作为尝试目标，受现场松弛范围限制 | 3次 |
| L3 | 可行时换到同目标另一个小位置 | 累计位移逐步增加，未通过L2不扩大 | 可选 |
| L4 | 返回A附近 | 记录实际回位误差，不把它算成纯算法漂移 | 伴随上述路线 |

距离和角度只是初始实验建议，不是机器人当前已具备的精度或限位。实际动作由现场测量结果决定，不要求碰到一米边界。采集保持连续，标明动作中、停稳、画面模糊区间，离线处理时选择质量合适的帧。

小平移用于验证多视角融合，原地转向用于检验朝向跟踪。视野里的桌椅距离可以大于机器人的运动范围，但被遮挡表面是否可见取决于真实相机位置。

**局部地图通过标准**

- 原始彩色、无损深度、CameraInfo相关参数和时间戳完整。
- PLY保存并重新打开非空，点云着色和实物轮廓对应。
- 已知尺寸误差有测量；先以5%以内为初始工程目标。
- 检查重复桌面、重影和明显拉伸；算法success不是独立的定位精度结论。
- 对同一原始数据可重复重建；至少一条有实际平移的数据通过检查。
- 地图坐标是首帧相机坐标，不自动等于机器人底座坐标。
- 静止恒等位姿融合仅作尺度/导出检查，不代替运动位姿估计。

**完整实验室地图如何继续**

先取得上述局部验证结果，再选择满足硬件条件的全室采集方式：

1. 若电脑/连接设备可随安全移动，并且外接供电支持行走：在确认的线缆管理条件下逐区人工单步采集。
2. 若固定连接只能覆盖一个工位：经现场规范停机并可靠支撑后转移到下一供电/连接工位，各工位独立采集。不同工位需要共视固定结构及可识别锚点，再做跨段配准；不能只把多个点云叠加就称为全室图。
3. 若能恢复适合的电池供电：单步模式保持不变，重新规划全室可通行路线。
4. 若课程允许安全拆装相机且决定采用电脑直连手持采集：它可作为全室地图的数据备选，但需要另做直连采集入口；现有SSH接收器不能直接代替，也不能把该数据说成机器人移动建图结果。

全室验收需要：覆盖列出的所有可达区域的可见结构、各区域地图在统一坐标系中相连、跨区没有明显错位，并保存全室图、分区原始数据、轨迹和覆盖记录。封闭柜内和始终不可见表面不计为已重建。

当前仍需补齐单步控制以及跨段配准/闭环优化后的重融合。已有增量里程计短测不足以承诺全室一致性。明天在当前约一米限制下先完成小规模验证，后续全室推进以实际可移动工位和供电条件为依据。
