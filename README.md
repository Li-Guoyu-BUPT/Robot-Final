# ROBAN 实验室重建与机器人交互

本仓库把项目按“功能代码、前端、建图数据集、文档”拆开，便于脱离现场机器人继续开发。

## 功能分区

| 目录 | 内容 |
|---|---|
| `src/robot_control` | 键盘/单步机器人控制与安全门控 |
| `src/online_mapping` | 机器人传感器采集、在线融合、网页后端和质量诊断 |
| `src/offline_reconstruction` | 图片/视频离线重建与点云查看 |
| `frontend` | 本地轻量前端、控制台、在线建图和图库入口 |
| `datasets/lab` | 实验室数据集说明、质量指标和结果元数据 |
| `docs` | 实验计划、记录模板和下游任务设计 |

## 当前功能

1. 人工单步操控机器人采集数据。
2. 电脑端持续在线建图与实时预览。
3. 图片离线重建稠密点云。
4. 前端图库中查看已保存地图，后续可扩展区域地图跳转和自动补扫。

## 本地运行

```powershell
python -m http.server 8000 --directory frontend
```

然后打开 `http://127.0.0.1:8000/`。机器人相关脚本需要 ROS Kinetic、现场网络和对应工作空间环境，详见 `docs` 与各脚本的参数说明。

## 数据集说明

原始照片、视频和大体积点云没有直接复制进 Git 发布目录，避免仓库膨胀；数据组织、批次、质量统计和可复现实验入口见 [`datasets/lab/README.md`](datasets/lab/README.md)。后续如需公开原始数据，建议使用 Git LFS 或 GitHub Release 附件。

## 安全提示

机器人控制脚本只应在有人现场看护、机器人有防跌支撑且确认本体状态后使用。不要把 SSH/VNC 密码、现场日志中的凭据或私有网络配置提交到仓库。
